One warning label for a time machine, 120 characters at most, written to get
the biggest laugh. The program writes the label to `/output/entry.txt`.

The label:

> WARNING: Do not bring souvenirs from the future. Customs in 1348 burns witches, and your phone counts.

It is phrased like a genuine safety notice: the real hazard is carrying
future objects into the past, and the surprise lands in the last few words.

## Run it

```sh
node main.ts
```
